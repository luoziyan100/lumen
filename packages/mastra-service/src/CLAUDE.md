# src/
> L2 | 父级: ../CLAUDE.md

新应用实现目录；旧运行时不参与生产依赖。

- `application.ts`：组合 AgentController、Memory 与每任务 Workspace；原生专家按项目配置、角色能力与独立调用目录隔离，关闭先排空父子输出和诊断评估；诊断仅取得当前模型快照，不继承研究工具或工作区；原生threadState恢复清单展示，持久挂起阻止模型切换。
- `model.ts`：本地档案到 SDK Gateway 的配置边界，模型网络通过 SDK 执行。

- `drain.ts`：按受信 Controller 的父任务 resourceId 等待主/子模型输出持久化，使停止先排空再取消快照；关闭时排空全部运行，单任务停止不等待其他会话。
- `server.ts`：认证保护的官方 HTTP/SSE 与产品入口；模型/角色/资料共用配置写锁，运行/待答时拒绝修改，资料保存后清理文件系统与项目角色缓存；请求超限明确返回 413，残缺附件包返回可重试的 400，未知错误仅在服务日志记录脱敏原因，不记录请求正文或凭证。
- 模型设置：保存期间暂停新执行请求，已有研究或待回答问题拒绝热切换；版本化网关避免同名模型复用旧地址缓存。新会话自动恢复原生待回答问题；用户停止持久取消，退出应用保留。

- `config.ts`：只读解析当前有效模型档案，凭证不进入日志或迁移输出。
- `start.ts`：显式隔离目录中的本机服务；持有内核独占锁后开放存储，原子发布私有 discovery，信号触发排空并释放所有权。

- `research/`：论文检索、引用、网页和 PDF 原生工具；网络与领域解析不依赖旧内核。
- `ingestion/`：有界 DOCX 正文和真实图像摄取；图片像素只进入当前模型请求，持久消息和事件保留文件引用。
- `http/`：限制原生框架路由与任务身份，使 HTTP 请求始终进入产品管理的会话与工作区。
- `lifecycle/`：在明确持有数据根独占权的启动边界结算崩溃遗留子任务，不重新执行模型或工具。

- `catalog/`：项目领域持久化与原生 Mastra thread 目录，提供标题、置顶、归档、分页和独立已读消息游标；消息与运行状态仍由框架持有。

- `settings/`：独立数据根中的模型档案与研究偏好，公开脱敏视图、服务内部网关配置和显式一次性导入。

- `migration/`：显式旧根到空新根的一次性离线导入，原事件及文件只读封存，合法历史进入原生 Memory。

- `deployment/`：显式 Node 24/工程/数据根的隔离 LaunchAgent，私有发现与日志、内核独占启动及认证就绪等待；不管理旧服务。

- `skills/`：用户/项目及已绑定来源 .lumen/skills 的发现、激活与安装；工具、HTTP 与执行只读根共用同一实时 registry。

- `execution/`：当前任务的 Node/Python 自动沙箱执行，按任务实时解析已安装技能只读根，保留 Seatbelt、域名代理、进程组取消与有限输出；显式 ask/deny 不被默认权限覆盖。
- `diagnostics/`：原生 trace 的采集、授权读取、脱敏标注与完整性导出；框架观测不冒充完整副作用审计。
- `agents/`：研究人格与专家职责；保留原人格，能力合同随原生工具更新。
- `workspace/`：任务产物、只读项目资料和跨会话事实记忆的原生文件系统挂载与工具。

application 组合父子共享预算及稳定专家历史；预算按会话 opaque model ID 读取冻结的计价/上下文窗口快照，避免忙会话模型切换污染旧步骤；liveSessionStates 从当前 Controller 和原生后台任务投影运行/等待状态，不为历史任务创建会话。server 暴露已授权的专家继续/预算入口并把状态投影接入目录。
