# evaluation/
> L2 | 父级: ../CLAUDE.md

诊断执行使用独立原生 Agent；不注册 Controller、Memory、Workspace、后台任务或生产工具。执行结果只附属于问题标注，不构成第二套任务状态。

- `types.ts`：执行完成与预期文本匹配分开的结果合同；不足证据明确 unavailable。
- `evidence.ts`：从已授权且脱敏的原生 trace 解析模型步骤、工具调用身份与用户输入；缺失、截断、脱敏或歧义拒绝回放；审批暂停步只以同推理完整chunk和明确恢复关系还原，重复恢复步精确去重；工具成功值与已记录错误分型。
- `recorded.ts`：内存录制模型与按调用身份/参数匹配的工具桩；不接入网络或真实工具；已记录的Error/AbortError通过原生异常通道进入下一轮模型，失败不伪装为成功值。
- `run.ts`：60 秒隔离 Agent 执行与结果判断；live 只使用宿主注入的当前模型，无工具与持久会话。

[PROTOCOL]: 变更时更新此头部，然后检查 CLAUDE.md

边界：回放完成只说明录制序列被消费，不代表原工具成功或答案正确。完全中断、无终态模型步骤、错误详情不完整时仍unavailable；不会自动重放真实副作用。
