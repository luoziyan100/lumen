# settings/
> L2 | 父级: ../CLAUDE.md

模型设置仅保存在调用方显式提供的数据根。公开 DTO 与服务内部凭证分离；原子落盘成功后才发布新的内存快照，更新失败保留上一版本。

- `types.ts`：设置面板的纯 DTO 与更新命令，公开档案只有 `hasApiKey/apiKeyMasked`。
- `schema.ts`：当前磁盘格式、输入验证及旧设置的显式规范化；无环境变量或正式目录回退。
- `profile.ts`：档案修改与模型选择规则；凭证不跨档案继承，掩码或空 key 不覆盖真实 key。
- `store.ts`：显式数据根中的 JSON 读取、串行更新和原子写入，一次性导入仅允许未初始化的目录。
- `runtime.ts`：生效配置转换到 SDK 网关、上下文容量、模型计价快照和视觉策略；凭证不通过公开 DTO 返回。
- `routes.ts`：脱敏 GET/PATCH 设置接口；保存前区分纯模型选择与完整配置，GET公开服务级 `busy` 运行状态供界面锁定完整编辑，保存后回调协调运行配置，不提供文件导入入口。
- `models.ts`：不可变配置版本到 Mastra gateway 的注册表；相同有效配置复用 providerId，只有有效配置变化才产生新版本，独立 providerId 隔离旧 SDK 缓存，OpenAI 兼容流只在正文/工具增量前遇到 `upstream_error` 时最多重试两次。

`store.secrets()` 只供服务内部诊断脱敏，覆盖所有档案凭证，不提供网络读取接口。

`store.toPublic()` 可用于 HTTP；`store.effective()/modelSettings()` 仅供服务组合。默认提供商地址只在运行配置中补齐，新档案不会继承其他档案的密钥。删除当前档案切到剩余第一项；全部删除后没有活动模型。损坏文件拒绝加载，禁止静默清空覆盖。

`settingsRoutes` 的 `withUpdate(work, patch)` 覆盖保存和运行通知，使组合层可阻止新的模型运行跨过切换边界。模型注册表仅在当前进程有效；会话恢复必须切到该进程注册的当前模型 ID，不能继续使用上次进程的 opaque ID。

`busy` 只表示服务中存在运行、挂起或排队的研究，不代替 PATCH 的最终互斥检查；状态可能在读取后变化。纯模型选择 PATCH 可穿过忙状态保存，完整配置仍以 `application.isBusy()` 为准；会话模型由其启动时的 opaque ID 固定，空闲或新会话才应用最新选择，预算按该 opaque ID 的模型计价和上下文窗口快照读取。

模型偏好、预算和采集开关只更新自身状态，不重新注册或遍历会话；档案名称等不影响有效模型的修改也复用当前注册版本。

模型重试只处理 HTTP 200 SSE 的流前上游临时错误；成功响应原样交给 SDK 持续读取，已产生正文或工具增量的请求不重放，非可重放请求与 Anthropic 配置保持原生行为。

researchBudget 是可选父子累计输入/输出 token 与美元上限；空对象取消限制。每个模型档案可记录特定 model 的每百万输入/输出价格，只有与当前模型完全匹配才计价；缺价保持未知，不推断免费。schema 验证正上限与非负价格，profile 负责替换预算和公开价格。

[PROTOCOL]: 变更时更新此头部，然后检查 CLAUDE.md

采集开关单字段更新不切换模型；`changed(settings, patch)` 根据实际变更通知对应能力，避免诊断设置清空当前网关。
