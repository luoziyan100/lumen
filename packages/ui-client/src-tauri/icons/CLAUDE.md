# icons/ — Lumen 应用图标
> L2 | 父级: ../CLAUDE.md

母版来自用户在2026-09-20提供的飞鸟与星芒水彩图。提取原图主体，沿水彩边缘补齐方形画布；1024母版不留透明边、不预裁圆角或叠加阴影，系统图标服务统一裁形，避免旧留白被再次缩放套底板。各桌面尺寸由同一母版重采样。

```text
icons/
├── icon.png                  # 1024px全幅母版
├── icon.icns / icon.ico      # macOS/Windows多尺寸容器
├── *x*.png                   # 桌面与Windows商店尺寸
├── android/ / ios/           # 历史移动端资源，现役桌面构建不引用
└── CLAUDE.md
```

成员清单
- `icon.png`：1024×1024全幅不透明母版；后续图标修改的唯一桌面来源。
- `icon.icns`：macOS应用/Dock/Finder图标，覆盖16–1024像素；以NSWorkspace实际系统合成图验证填充而非只看原PNG。
- `icon.ico`：Windows应用图标，覆盖16、24、32、48、64、128、256像素。
- `128x128.png`：128×128桌面派生图，与母版保持同一图案和水彩背景。
- `128x128@2x.png`：256×256桌面派生图，与母版保持同一图案和水彩背景。
