# views/
> L2 | 父级: ../CLAUDE.md

- `TopicsEntry.tsx`：S2–S3 过渡入口，S4 由 StudioApp 取代。只列真实主题（`/lumen/topics`）、新建主题、列出主题下会话并打开（Conversation）或新开（Welcome），可开工作区/设置/研究角色；不画白板、不放假数据。
- `Conversation.tsx`：原生消息与任务/用量、审批/追问；原生reasoning独立思考轨迹默认折叠并结束收口；工具按轮次合卡，运行首次展开、用户控制开合、最近六步窗口，成功定稿隐藏过程、失败/未完成保留，工具轮公开旁白收入Thought；原光圈/点云球恢复，累计用量放入右轨折叠区，恢复chat-stage/messages/messages-content与原消息壳；滚动区随输入坞高度让位，轮次轨在窄栏/阅读器下按原规则隐藏；审批/问询与进行中的专家任务挂输入坞上方(完成的不占对话流)，对话底部始终是最新消息，1.82 的并行 pendingApprovals 逐条展示，审批/回答命令 ack 未认领时如实报错；服务端专家目录(右轨，经 Files 注入 WorkspaceRail)支持用户明确补充新任务后继续，等待原审批不重复提交；恢复历史附件、消息复制、长用户正文折叠与轮次轨道；已有子任务轮询同步专家派生用量，停止后晚到结果仍可见；工具活动只展示原生进行态，完成/失败结果留在历史；上滑或离开底部后停止追新，程序贴底不恢复跟随，回到最新才重新贴底并确认可见已读；切任务隔离迟到结果，可见且跟随底部时确认持久消息游标，相对引用在阅读器打开；会话投影拆分稳定历史与当前轮，widget 发送回调保持引用稳定。
- `Files.tsx`：原进度/工作目录与阅读器切换；主题工作区、主题记忆与关于你的记忆三个范围保留在管理菜单，附件可按资料库条目（scope=library）只读打开；迟到加载不覆盖编辑草稿，保存后清除旧导航；HTML/PDF/Markdown/图像沿原阅读器边界预览；正文引用支持相对路径和 PDF 页码；阅读器单顶栏提供格式标签、复制源码、受控原件打开与下载，支持拖拽记忆宽度，顶栏提供文档居中开关并回报阅读器开合；成功导航回传当前稿，运行中每五秒先用 ETag 检查当前文件，版本未变复用预览，变化才读取正文，后台刷新不重绑定当前稿；加入资料库整批互斥，首次失败保留错误。
- `Skills.tsx`：技能发现、管理安装/移除，只有用户层；选择回到输入卡技能菜单，不重复添加参数栏；目录上传保留脚本/资源/空目录和执行位，在任务私有临时目录校验后原子安装。
- `Settings.tsx`：原横向set-row表单、逐行模型增减、统一图标的供应商卡操作与密钥掩码；模型、研究偏好与外观三个分类在运行中仍可浏览，仅保存请求阻止切页；模型配置和研究偏好写入遵守运行门禁，外观本机即时切换；不提供研究预算编辑，服务端用量与运行保护保留；模型价格按具体模型关联，费用未知不估算。
- `chrome/`：皮肤面板与独立宽度拖拽交互。
- `workspace/`：独立于右轨显隐加载主题工作区产物和原生任务，首次新路径通知展开；原进度/目录卡片与宽度记忆。
- `conversation/`：草稿/附件、原生任务用量和多选追问的局部呈现；思考/过程、专家与长输入共用原卷帘，关闭保留内容和草稿。
- `workbench.css`：复用原 titlebar/sidebar/chat/composer/reader 形制、tokens与图标组件尺寸，不再重缩放导航轮廓；PDF 面板约束纵向高度并独立滚动，宽页完整保留横向滚动范围、页面不被 flex 压缩；移除泛化label规则以免污染外观滑杆，末尾附过渡入口的主题/会话列表样式（随 TopicsEntry 退场）；窄窗口阅读器覆盖呈现(文档居中在窄窗退回同一覆盖)；会话灯支持手动已读/未读，当前会话标未读先同步切到档案页、卸载自动阅读确认，再串行写入。

卷帘边界：思考/过程和目录使用 `components/disclosure/CurtainFold`；新增模型价格、专家、用量等详情用 `Disclosure`，收起保留草稿。浮层菜单、左右整栏显隐继续沿各自原交互。

错误呈现：`Conversation.tsx` 独立展示运行错误与连接错误；运行错误保持可见到下一轮开始，只有连接/读取错误提供重新连接入口，成功补取历史不代表模型执行成功。
