- `WorkspaceApp.tsx`：项目/会话选择与研究工作台组合；先校验本地选择属于当前数据根，失效时回到目录，不创建空线程；项目改名/归档、会话搜索/置顶/归档恢复与角色管理都走新产品 API；显式打开当前会话诊断；项目/会话行右键操作显式目标，⌘K 打开独立快跳；全局目录分批聚合且每十五秒无重叠刷新，项目预览和最近记录进入主列会话档案；原顶部双侧导航与紧凑侧栏回归，移除会话内重复标题/状态/模型栏，诊断入口随侧栏显式会话目标；新建项目用原420px无遮罩卡，欢迎态复用完整Composer且按需创建会话，项目/会话操作收进菜单，工作区只在首次发现新产物时展开、尊重手动收起；可写当前稿按身份隔离并在发送时冻结上下文；外观订阅挂在工作台生命周期。
- `Conversation.tsx`：原生消息与任务/用量、审批/追问；原生reasoning独立思考轨迹默认折叠并结束收口；工具按轮次合卡，运行首次展开、用户控制开合、最近六步窗口，成功定稿隐藏过程、失败/未完成保留，工具轮公开旁白收入Thought；原光圈/点云球恢复，累计用量放入右轨折叠区，恢复chat-stage/messages/messages-content与原消息壳；滚动区随输入坞高度让位，轮次轨在窄栏/阅读器下按原规则隐藏；审批/问询挂输入坞上方；服务端专家目录支持用户明确补充新任务后继续，等待原审批不重复提交；恢复历史附件、消息复制、长用户正文折叠与轮次轨道；已有子任务轮询同步专家派生用量，停止后晚到结果仍可见；工具活动只展示原生进行态，完成/失败结果留在历史；上滑或离开底部后停止追新，程序贴底不恢复跟随，回到最新才重新贴底并确认可见已读；切任务隔离迟到结果，可见且跟随底部时确认持久消息游标，相对引用在阅读器打开；会话投影拆分稳定历史与当前轮，widget 发送回调保持引用稳定。
- `Files.tsx`：原进度/工作目录与阅读器切换；完整文件、外部资料和记忆导航保留在管理菜单；外部绑定复用原生目录选择，迟到加载不覆盖编辑草稿，保存后清除旧导航；HTML/PDF/Markdown/图像沿原阅读器边界预览；正文引用支持相对路径和 PDF 页码；阅读器单顶栏提供格式标签、复制源码、受控原件打开与下载，支持拖拽记忆宽度；成功导航回传当前稿，运行中每五秒先用 ETag 检查当前文件，版本未变复用预览，变化才读取正文，后台刷新不重绑定当前稿；共享上传整批互斥，首次失败保留错误。
- `Skills.tsx`：任务技能发现、管理安装/移除，默认全局；选择回到输入卡技能菜单，不重复添加参数栏；目录上传保留脚本/资源/空目录和执行位，在任务私有临时目录校验后原子安装。
- `Settings.tsx`：原横向set-row表单、逐行模型增减、供应商卡悬停操作与密钥掩码；原设置分栏中的模型档案、研究偏好、预算与外观；模型价格按具体模型关联，费用未知不估算；凭证单向保存，运行中切换由服务拒绝。
- `chrome/`：恢复原侧栏、皮肤面板与独立宽度拖拽交互，不读取旧协议。
- `workspace/`：独立于右轨显隐加载共享/本会话产物和原生任务，首次新路径通知展开；原进度/目录卡片与宽度记忆。
- `conversation/`：草稿/附件、原生任务用量和多选追问的局部呈现；思考/过程、专家与长输入共用原卷帘，关闭保留内容和草稿。
- `workbench.css`：复用原 titlebar/sidebar/chat/composer/reader 形制和 tokens；PDF 面板约束纵向高度并独立滚动，宽页完整保留横向滚动范围、页面不被 flex 压缩；移除泛化label规则以免污染外观滑杆，项目与会话共用受限滚动列表，账户区保留在底部；窄窗口阅读器覆盖呈现；会话灯支持手动已读/未读，当前会话标未读先同步切到档案页、卸载自动阅读确认，再串行写入。
