# mastra/
> L2 | 父级: ../../CLAUDE.md

桌面唯一入口直接消费 Mastra 原生消息与 displayState，不转换回旧 WS 事件。默认发现正式数据根，显式参数或环境变量保留隔离预览；发现失败展示重试入口。

- `data/`：产品 HTTP 与官方 SDK、会话订阅/重连补取。
- `studio/`：新形态外壳（桌面唯一工作台，原型 v7 骨架的圆角面板与同线头部）——左栏主题与状态灯、中栏分段视图（白板可用，其余如实占位）与原件分屏、右栏「素材」、对话精灵；白板对人只读，按视口宽度在显示层重排 1–3 列。
- `views/`：外壳复用的对话、欢迎、阅读器、设置与技能；原生消息/审批/追问都在这里，不另建事件协议。
- `diagnostics/`：受信 trace、问题标注、显式录制回放/当前模型评估、导出和离线包查看；运行完成与文本匹配分开，缺证据如实显示。
- `agents/`：全局角色（内置 > 用户 > 插件）来源、权限、启停和显式重载；不接管子任务执行。
