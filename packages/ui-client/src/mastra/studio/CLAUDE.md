# studio/ — 新形态外壳（主题 + 白板学习工作台）
> L2 | 父级: ../CLAUDE.md

产品宪法 `doc/studio/`（主检出），P0 合同 `briefs/active/studio-p0/`。白板是主题的共同草稿，对话退成精灵；P0 白板对人只读（不圈、不钉、不改）。

- `StudioApp.tsx`：桌面唯一工作台。左栏主题、中间视图标签（白板可用，沉淀/概念图/灵感/全部如实占位）与原件分屏、右栏材料、精灵；记住上次的主题；主题忙且没开着对话时直接打开那段在运行/等你的对话（R1）。
- `TopicPanel.tsx`：`useTopics` 3 秒轮询（状态灯跟上后台运行）；主题列表、运行/等你灯、新建主题、设置与研究角色入口。
- `Board.tsx`：张标签与 ＋、DOM + CSS transform 平移（拖空白处/滚轮）与缩放（⌘/Ctrl+滚轮、按钮、看全貌）；按列实测高度重排避免重叠；白板边界与「已用 n / 8」；AI 正在画提示；小部件同时最多运行两个（点开的挤掉最早的）；点卡跳块高亮。
- `Block.tsx`：单块渲染——文字（Markdown）、梯子（高到低、你在这里、雾线、断点）、表格（留给你猜的格）、小部件（WidgetFrame 或占位）；出处签点开原件，无出处即「AI 推断」（R9）；已被取代变灰（R10）。
- `useBoard.ts`：白板列表与选中那张；刷新靠对话里白板工具完成信号（signal）+ 运行中 5 秒 ETag 兜底，不建第二套事件协议。
- `Materials.tsx`：`useMaterials` 与右栏「这个主题用到的」——分你带来的/AI 找来的，上传、粘贴链接、不再引用（只断本主题引用，原件留在资料库，R15），点开在中间分屏读。
- `Sprite.tsx`：对话精灵——球 ↔ 可拖动浮窗 ↔ 停靠右侧，形态存 localStorage 并夹在窗口内；本主题对话列表（3 秒轮询）、新对话（主题忙时禁用并说明，R1）、Welcome/Conversation、专家目录与诊断。
- `studio.css`：只用现有 tokens；控件与文档岛实色。
