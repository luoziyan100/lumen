# studio/ — 新形态外壳（主题 + 白板学习工作台）
> L2 | 父级: ../CLAUDE.md

产品宪法 `doc/studio/`（主检出），P0 合同 `briefs/active/studio-p0/`。白板是主题的共同草稿，对话退成精灵；P0 白板对人只读（不圈、不钉、不改）。

- `StudioApp.tsx`：桌面唯一工作台，照原型 v7 骨架：canvas 底上 8px 间距的圆角面板（左栏主题、中栏、右栏材料、停靠的精灵），每个面板首行 50px 头部同线。中栏头部只有按所在段中线居中的分段视图（白板可用，其余如实占位；主题名进 aria-label 与窗口标题），分屏时阅读器在中栏右段、头部同一行；精灵球挂在白板区右下角；记住上次的主题，刚建的主题不被「选第一个」顶掉；主题忙且没开着对话时直接打开那段在运行/等你的对话（R1）。左右栏可收起到宽 0（展开按钮在中栏头部最左/最右，分屏时右侧的落在阅读器头，铺满时左侧的也在阅读器头）；阅读器三态：关闭 / 分屏 / 铺满中栏（白板 display:none 但保持挂载与相机，精灵球改挂阅读器右下；Esc 或还原按钮回分屏）；从素材或出处签打开一律进分屏。
- `Panes.tsx`：`usePanes`（左右收起与分屏比例存 `lumen.studio.panes`；⌘B 主题栏、⌘⌥B 素材栏，按物理键位认 B）、`splitBoardWidth`（白板段 = 比例 × 内宽，夹在 [360, 内宽 − 420]，放不下时白板保 360、先压阅读器；studio.css 的 clamp 同一规则）、`PaneToggle`（PanelIcon，右栏镜像；aria-expanded、aria-controls、带快捷键的 title）、`Splitter`（8px 命中区、悬停 1px 线、拖动/双击各一半/方向键）。
- `TopicPanel.tsx`：`useTopics` 3 秒轮询（状态灯跟上后台运行）；头部「主题 ＋ 收起」（＋ 在列表顶出输入框，回车建、Esc 取消；去掉 Lumen 品牌字，窗口标题已经是 Lumen）；底部同一行的研究角色与设置。
- `Board.tsx`：左上角浮层（多张时才有张标签 · ＋；张标签单行、最宽 160 省略、title 全名、放不下横向滚动，浮层恒高 30，画布起点 BOARD.TOP=64 在它之下（W2）；铺满时视口宽 0 不重排；不显示已用块数，上限与 R11 在服务端，写满时边框标签如实写「已经写满」）、DOM + CSS transform 平移（拖空白处/滚轮）与缩放（⌘/Ctrl+滚轮、按钮、看全貌）；默认 100% 从左上角开始，按 `layout.ts` 重排；贴着内容的白板边框；AI 正在画提示；小部件同时最多运行两个（点开的挤掉最早的）；点卡跳块高亮；右下角缩放条。
- `layout.ts`：显示层排版纯函数——视口宽度决定 1–3 列与列宽（300–440），按服务端顺序（列 x、再 y）排进最矮的列；服务端坐标不动。
- `Block.tsx`：单块渲染——标题是块里最强的字，不重复「AI 画的」（署名在 aria-label）；文字（Markdown，mermaid 按宽缩放、无横向滚动）、梯子（高到低、你在这里、雾线、断点画在两级之间）、表格（单元格换行、留给你猜的格）、小部件（WidgetFrame 固定浅档、高度跟内容，或占位）；底部一行出处签，点开原件，无出处即「AI 推断」（R9）；已被取代变灰（R10）。
- `useBoard.ts`：白板列表与选中那张；刷新靠对话里白板工具完成信号（signal）+ 运行中 5 秒 ETag 兜底，不建第二套事件协议。
- `Materials.tsx`：`useMaterials` 与右栏「素材」（界面用词；对象名仍叫材料）——头部右侧收起按钮、每行类别轮廓（PDF/文档/网页用文档、图片用图片，18，随文字色，不用文字徽标）、一行添加（粘贴链接回车 + 上传图标）、一个按加入时间倒序的列表（不分组不计数）、meta 放「AI 找来」·格式（PDF、网页、扩展名）·来源·读到哪，板上引用数进 title、不再引用（只断本主题引用，原件留在资料库，R15），点开在中间分屏读。
- `Sprite.tsx`：对话精灵——球（portal 进白板区右下角，不压右栏）↔ 可拖动浮窗 ↔ 停靠成第四个面板，形态存 localStorage 并夹在窗口内；本主题对话列表（3 秒轮询）、新对话（主题忙时禁用并说明，R1）、Welcome/Conversation、专家目录与诊断。
- `studio.css`：骨架变量在顶部——四级字阶（14/600、13.5、11、12）、14px 内边距、50px 头部、30px 控件、左右栏宽（收起为 0，`--dur-base` 过渡，减弱动效时瞬时；中栏用负外边距吃掉那一侧间距，外边距仍 8px），全文件只引用它们；只用现有 tokens；控件与文档岛实色。
