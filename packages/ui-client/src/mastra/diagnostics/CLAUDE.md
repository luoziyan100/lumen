# diagnostics/
> L2 | 父级: ../CLAUDE.md

会话诊断分开原生 trace、用户评语、显式评估和旧版归档。所有请求经过 LumenApi 认证 HTTP；录制回放/当前模型评估只由按钮发起，离线包和旧版证据仅查看。

- `Diagnostics.tsx`：工作台显式入口，组织 trace、标注/评估与离线包查看，刷新标注读取持久结果；采集开关可热修改，迟到响应不能改变已关闭界面。
- `Trace.tsx`：共享Disclosure呈现原生span层次与脱敏负载，保留缩进和只读文本边界，标注准确关联 trace/span。
- `Cases.tsx`：标注新增/编辑与显式评估请求；API/会话切换重建局部状态，同 tick 操作互斥，未保存修改禁评估，失败留稿，迟到结果不覆盖另一标注。
- `Evaluation.tsx`：两种运行入口和后端持久结果；单列执行状态与预期文本匹配，缺证据不冒充成功，当前模型的无工具单次请求明确提示费用。
- `Coverage.tsx`：当前采集状态、裁剪/脱敏和共享Disclosure中的已知覆盖缺口，不把成功步骤称为完整审计。
- `files.ts`：8 MiB 文件边界；桌面原生保存、浏览器下载以及只读加载，取消不落盘。
- `diagnostics.css`：诊断弹层与共享Disclosure触发器局部样式，沿用 Lumen token 和 Kumo 控件；滚动体独用 `md-dialog-body`，禁止复用 Markdown 的 `md-body`，否则会限高所有聊天正文。
- `legacy/`：已授权旧版证据的分页/详情入口；归档完整性由服务核对，缺损与空状态分开，不重放旧运行时。

离线包查看仅核对 JSON 完整性和脱敏内容，不认证来源、不执行模型或工具。录制回放不调用外部模型或真实工具；重新评估使用当前模型发送一次无工具请求。两者的执行/判断由后端保存到标注，文本包含判断不等于回答质量通过。
