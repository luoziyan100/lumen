- `ui-assert-objects.mts`: browser acceptance for the objects in the product, with its own isolated fixture (the model holds the first section until the script opens a gate) and vite (PORT, default 5191). Objects are aria-hidden, untabbable and never take focus. The box's card carries the newest takeaway, and a click on the box changes nothing else. At rest, hovered and opened each object settles: no transition still running and only looping animations (the objects move on purpose, so pixels are not compared). WebKit captures every object at rest and open. `--no-easel` skips the easel. Do not edit source while it runs: vite's reload replaces the page mid-capture.

- Language (i18n): `ui-assert-panels.mjs` and `sprite-move-assert.mjs` take `LOCALE=en|zh` (default zh) and `PORT` (default 5183). The language is seeded before the page loads, and every visible word they click or compare comes from that locale's catalog, so both pass in either language with unchanged conditions. Check names stay Chinese.

运行于仓库根：先编译 Swift 驱动到 `/tmp/lumen-sprite-native`，启动 fixture 和5183，再依次执行原生与浏览器断言，避免受控模型流互相覆盖。输出目录从参数传入，证据不进入产品。
