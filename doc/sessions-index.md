> 侧栏是门,会话页是档案室。对用户只说**会话**,不说 task / Tasks / 任务。

## 名词

| 概念 | 产品中文 |
|---|---|
| 侧栏「最近」溢出 | 查看全部会话 |
| 项目树溢出 | 查看全部(预筛该项目) |
| 主列档案室 | 会话 |

| 翻页 | 上一页 / 下一页 |
