## 碰到的问题与卡点

1. **旧 PID 71847 占数据根（卡点，需要你来）**  
   Spec 禁止盲杀未知来源进程。要让新服务被 launchd 托管，需要你先停掉该 node，再开常驻或跑 `npm run launchd:install`。不停它，F16 会一直报冲突——这是对的。

2. **`main.rs` 编译**  
   F16 交接等待里 `state()` 临时值被借用，Rust E0716。已改成先绑定 `Sidecar` 再锁。随后 `tauri:build` 通过。

3. **F16 安装会碰到自己的验收现场**  
   修完「误报成功」后，本机正好处于误报留下的活实例。安装失败不是回归，是合同生效。
