# Lumen 的 Mastra 架构

状态: 现行运行架构，2026-09-19。正式切换、旧界面恢复、范围补齐及实机组合操作已完成；本文件描述实际职责和明确限制，交付证据见 `briefs/archive/mastra/plan.md` 第9节。

## 执行与数据归属

```text
Tauri / React
  ├─ 产品 HTTP：项目、设置、文件、技能、角色、诊断
  └─ 官方 MastraClient：消息、SSE、审批、问答
         ↓
Hono 认证与固定会话身份
         ↓
AgentController → 主 Agent → 原生工具 / 专家 Agent
         ├─ Memory / LibSQL：thread、消息、任务状态、挂起、后台任务、trace
         └─ Workspace：任务目录、专家独立目录、只读资料
```

旧 core/runtime、WS 协议、UI reducer 和重复消息存储已从当前源码退役。没有把旧执行器藏在 Mastra 工具里。

Mastra 持有模型循环、工具回灌、SSE、暂停/恢复、后台调度和线程历史。Lumen 持有论文检索/阅读算法、模型档案、项目目录、材料权限、角色配置、文件产物与界面。领域算法不依赖旧包。

版本锁：core `1.67.0`、memory `1.30.0`、libsql `1.23.0`、hono 适配器 `1.7.9`、client-js `1.46.0`、observability `1.17.8`。模型使用当前框架兼容的 AI SDK v2/v3 provider 接口；不把不兼容的新主版本混入运行。

## 项目、文件与会话

会话 `resourceId` 和 `threadId` 固定为 `projectId:taskId`。所有原生 HTTP 入口先校验产品归属；历史读取只授权，不为了读消息而实例化执行 Session。

```text
~/.lumen-mastra/
├── mastra.sqlite                 # 框架数据真源
├── catalog.sqlite                # 项目与已读游标，不保存消息或运行状态
├── settings.json                 # 私有模型档案，HTTP只返回掩码
├── subagents/                    # 用户自定义角色
├── skills/                       # 用户技能
├── projects/<project>/
│   ├── source.json               # 显式外部只读绑定
│   ├── shared/                   # 托管项目资料
│   ├── memory/                   # 跨会话事实与MEMORY.md索引
│   ├── skills/、subagents/        # 项目配置
│   └── tasks/<task>/             # 本次研究产物
│       └── workers/<role>-<id>/   # 可写专家的独立产物
└── archive/legacy-v1/             # 导入原件、原始事件与来源映射
```

外部资料只验证和读取；绑定不等于归档了外部文件。文件操作使用 contained LocalFilesystem，拒绝路径/链接越界。箱内代码默认自动执行，由 Seatbelt 约束且默认断网；允许的网络流量只能经过受限域名代理。主任务及可执行专家按当前项目实时发现用户/项目/已绑定来源的技能包，只读脚本与资源；来源技能复用资料根的真实路径校验。Homebrew/POSIX命令发现与嵌套Node代理继承保留原行为。

会话目录使用原生 thread 元数据管理标题、归档、置顶。已读游标在产品库保存实际看过的最新持久消息 ID，手动未读使用明确的空游标；不触碰框架 thread 时间。客户端串行提交阅读状态，迟到自动确认不能覆盖手动未读；目录运行/等待灯只投影已有 Session 和原生后台任务。

## 专家与用户决策

内建 reader、searcher、verifier、explore、plan、general-purpose 六类角色。配置按项目分层加载，公开工具名保持 `agent-<角色>`，内部 Agent ID 包含项目与定义摘要，后台恢复不会混用同名角色。委派使用原生messageFilter隔离父会话历史，材料只经prompt/contextFromRefs显式传入，避免把父会话全部工具历史复制给每位专家。

只读专家不能写文件。可写专家只能修改各自调用目录，父任务资料仅供读取/复制。主研究者审阅后合并产物。旧 Git worktree 自动合并协调器由这种文件交付边界替代，避免多专家争写最终报告。

不开放嵌套委派。合法专家委派和工作区技能安装默认自动执行；未知 other 类工具不统一放行。Controller 保留会话中显式 ask/deny，代码禁止策略在主/子共享执行环境入口再次检查，不能借专家绕过。可执行/自定义专家保持前台，其他内建角色支持原生后台模式；本次修复不扩大后台角色集合。后台任务由 Mastra 管理并发、超时与取消，默认不重试有副作用的工作。

角色、资料与完整模型配置变更共用串行配置边界；有执行、审批、持久待答或后台子任务时拒绝修改。纯模型选择可在运行中落盘，当前会话保留启动时的 opaque 模型 ID，新会话或空闲会话才应用新选择。单独切换诊断采集不更改模型。

## 长任务与恢复

主运行默认最多 100 次模型步骤、1200 秒活动时间，问答/审批等待不计。专家有更小角色步数限制，末步关闭工具以请求总结；空回复、过滤和截断向父Agent返回具体终止原因，不能视为核对完成，也不自动绕过内容过滤。两专家真实总结已经验证；报告事实仍需独立复核，执行成功不等于结论正确。另有可选父子累计输入/输出 token 与美元费用准入：原生 processor 在请求前串行预留，按当次真实 usage 去重结算到 threadState。原生恢复可在同run内重置step，准入键因此包含response messageId；输入/输出通过同一processor原生state固定配对，重复回调不重复记账，旧收据保持原值。价格按模型明确配置，未知费用或未结算调用不当作零；这是保守预估准入，不能承诺供应商最终账单绝不超限。

输入使用原生 TokenLimiter，预留模型窗口的20%，保留连续近期上下文；缺省窗口128k。消息原文仍持久保存，`read_history` 只读当前任务历史，项目记忆保存稳定事实。没有另造摘要库或消息存储。图片像素只进入当前模型请求，持久事件保留文件引用；vision=off同时关闭图像工具与输入处理。

空回复由原生 processor 反馈纠正一次，再为空则明确失败。锁定版 Controller 对终态 TripWire 的展示存在差异；上下文/预算/空回复的最终失败以普通 Error 进入原生错误路径，裁剪和重试算法仍由框架执行。

退出/停止先取消父子执行，再等待公开 stream/resumeStream 输出完成和落盘；之后销毁 Session、Mastra、Workspace与数据库。窗口隐藏不结束研究。进程异常重启将残留后台工作结算为中断，不自动重放副作用。用户 Stop 持久取消待答；普通退出保留待答。专家支持用户明确提出新要求后继续：稳定产品 ID 映射历次原生 Memory 子线程，保持原工作目录，读取已存上下文后重新进入原生委派与审批。旧 invocation 的挂起精确清理，保留其它审批引用的共享快照；不自动重放已执行工具。

## 诊断与历史迁移

官方 Observability/MastraStorageExporter 只向本机 LibSQL 输出 trace。采集、读取、标注和导出都会脱敏。LibSQL不支持的metrics信号不注册导出；不拦日志掩盖失败。

诊断提供父会话可验证跨度、问题标注、SHA256完整性导出与离线只读回看。独立子资源或归属不能验证的跨度明确省略。显式评估使用独立 Agent：录制模式只用内存模型/工具桩，当前模型模式无工具且不写生产会话；录制回放保留失败/取消为 error-text，按原生工具调用及审批恢复关系重建，避免跳过暂停步骤；缺失、截断、脱敏或归属歧义仍返回 unavailable。预期文本匹配与执行完成分开，匹配不代表语义质量。仍不提供原始HTTP、完整副作用审计或逐位执行重放。

旧证据通过当前会话授权及迁移映射只读浏览，原数据库校验后复制到临时目录查询，正文按清单和内容哈希核验并脱敏。旧证据不混入新trace，也不恢复旧执行器。主子用量由原生步骤usage按身份去重写入thread状态，界面分别展示主/子/合计；计量与预算采用明确的不同语义，不承诺供应商账单硬上限。

旧根离线导入空新根。原事件、文件、子历史和配置完整归档；合法会话历史进入原生存储，跨事件迟到工具结果按明确调用ID配对。系统催促保留为来源元数据，不伪装成用户消息。导入走框架公开存储接口保留正文空白，再逐消息验证ID、时间、角色与内容。

源码退役前备份所有原字节并核对SHA256。旧数据根与旧应用二进制保留用于回退；正式切换只在新根验证后替换服务/桌面入口。

## 桌面与开发

Tauri薄壳默认 `~/.lumen-mastra`，只唤醒已注册 `com.lumen.mastra`，不持有sidecar，不自行安装旧服务。发现失败可重试，不能回到旧协议。开发和预览使用独立数据根/label。

前端直接消费原生消息和displayState。先订阅、再补快照与持久历史；身份/连接世代隔离迟到响应；服务地址变化以有限退避重新发现，避免永久沿用旧discovery。文件、PDF、Markdown、HTML、widget沿用已有渲染与沙箱。PDF读取允许必要的Blob来源，页码跳转只滚动阅读器容器；工具completed状态不再显示为执行中。导出文件只写用户在原生保存对话框中选择的位置。恢复迁移前的玻璃皮肤/外观、侧栏项目树/会话索引/快捷搜索/右键菜单、输入卡/斜杠技能选择、长消息折叠/复制/历史附件和轮次导航；离开底部可回到最新并恢复跟随，输入框随草稿增高至168px；累计过程默认折叠。阅读器恢复复制、宽度记忆及受控打开真实本机原件以保留相对资源。完整技能目录通过显式文件选择上传，保留脚本、二进制资源、空目录和执行位；安装复用服务原子发布，不执行包内代码。
